# Dream Transit Website

Responsive transportation website starter for Dream Transit. Public branding omits “LLC” as requested.

## Preview locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser (or use the VS Code Live Server extension).

## Files
- `index.html` — page content and ride-request form preview
- `styles.css` — responsive styling
- `script.js` — mobile navigation and demo form behavior
- `assets/` — local photos used by the website

## Important before launch
The ride-request form is **not connected** to a server and does not store or send form submissions. Do not accept real customer details through this preview. Before launch, connect a secure backend, implement authentication and database row-level security, configure team-only access, and set up email/SMS notifications. A submitted request should remain pending until your team approves it. Do not place secret API keys in frontend files.

Review all service descriptions, accessibility claims, operating hours, rates, service area, privacy terms, and contact details before publishing. The office address is shown as `1221 S Main St` without an unverified city or ZIP code.
